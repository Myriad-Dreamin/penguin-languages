# @penguinharness/language-swift

Swift syntax highlighting for [PenguinHarness](https://github.com/Prism-Shadow/penguin-harness).

| Fence   | File extensions |
| ------- | --------------- |
| `swift` | `.swift`        |

Install it from a PenguinHarness server's **Plugins** page, or list it in a Project's
`.project_config.toml`:

```toml
[plugins]
"@penguinharness/language-swift" = "*"
```

The grammar is `@shikijs/langs/swift`; upstream attribution and licensing ride with that package.
See the [repository README](https://github.com/Myriad-Dreamin/penguin-languages) for how it works.
