# @penguinharness/language-kotlin

Kotlin syntax highlighting for [PenguinHarness](https://github.com/Prism-Shadow/penguin-harness).

| Fence                 | File extensions |
| --------------------- | --------------- |
| `kotlin`, `kt`, `kts` | `.kt`, `.kts`   |

Install it from a PenguinHarness server's **Plugins** page, or list it in a Project's
`.project_config.toml`:

```toml
[plugins]
"@penguinharness/language-kotlin" = "*"
```

The grammar is `@shikijs/langs/kotlin`; upstream attribution and licensing ride with that package.
See the [repository README](https://github.com/Myriad-Dreamin/penguin-languages) for how it works.
