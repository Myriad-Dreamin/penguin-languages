# @myriad-dreamin/penguin-language-csharp

C# syntax highlighting for [PenguinHarness](https://github.com/Prism-Shadow/penguin-harness).

| Fence                | File extensions |
| -------------------- | --------------- |
| `csharp`, `c#`, `cs` | `.cs`, `.csx`   |

Install it from a PenguinHarness server's **Plugins** page, or list it in a Project's
`.project_config.toml`:

```toml
[plugins]
"@myriad-dreamin/penguin-language-csharp" = "*"
```

The grammar is `@shikijs/langs/csharp`; upstream attribution and licensing ride with that package.
See the [repository README](https://github.com/Myriad-Dreamin/penguin-languages) for how it works.
